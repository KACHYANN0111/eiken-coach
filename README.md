# 英検2級 AI学習コーチ

毎日の10分で、英検2級合格に必要な力を伸ばす総合学習Webアプリ（API・外部ライブラリ不要）。
単語は 準2級・2級・準1級・1級 に分けて収録し、級ごとにテストできます。

## 使い方

### スマホアプリ版（iPhone / Android）
https://kachyann0111.github.io/eiken-coach/ をスマホで開き、ホーム画面に追加します。

- iPhone：Safari の共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
- Android：Chrome の「アプリをインストール」（またはメニュー︙ →「ホーム画面に追加」）

ホーム画面のアイコンから全画面で起動し、一度開けばオフラインでも使えます。学習記録はその端末内に保存されます。

### claude.ai 公開版（ログインして使う・端末間で記録を同期）
https://claude.ai/artifact/Fc9KJbfqZbvcTZiZjqZ5EB を Safari で開く（claude.ai にログイン）。
共有メニュー →「ホーム画面に追加」でアプリのように起動できます。
学習記録は本人専用のクラウド領域に保存され、iPhone と PC で共有されます。

### Mac で（ローカル版）

```bash
node server.js
```

ブラウザで http://localhost:8080 を開く。ローカル版の記録はそのブラウザ内（localStorage）に保存されます。

### 公開版を更新する

```bash
node build.js
```

`dist/eiken-coach.html`（全ファイルを1つにまとめたもの）ができるので、それを公開し直します。

## 構成

| パス | 役割 |
| --- | --- |
| `index.html` / `css/style.css` | 画面の土台・デザイン（PC / タブレット / スマホ対応、iPhone のセーフエリア対応） |
| `js/config.js` | 試験形式・語数制限・級の一覧・公式リンク・AI設定 |
| `js/store.js` | 端末内保存（localStorage）＋公開版でのクラウド同期、日別集計、連続学習日数 |
| `js/coach.js` | 単語の出題アルゴリズム（級別）、苦手分析、今日のおすすめ / 今日の10分 |
| `js/ai.js` | AI 機能のインターフェース（現在はローカル判定） |
| `js/data/words-*.js` | 単語（準2級・2級・準1級・1級）。各行：英単語｜意味｜品詞｜重要度｜頻出度｜カテゴリー｜例文｜訳 |
| `js/data/phrases*.js` | 熟語・重要表現（級別） |
| `js/data/*.js` | リーディング・リスニング・ライティング・面接のオリジナル問題 |
| `js/views/*.js` | 各画面 |
| `build.js` | 公開版（1ファイルHTML）を作る |

英検公式の過去問はアプリに転載せず、公式サイトへのリンクのみを掲載しています。
